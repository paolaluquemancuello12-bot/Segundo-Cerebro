# Localización

_Fuente: `RAW/2026-10-15-negocio.md`_ (§1.2, §4.5, §10.6)

Traducir no alcanza: el producto tiene que **parecer creado para ese país**.

## Checklist al adaptar a un país
- [ ] Idioma y variante (EN-US ≠ EN-UK; PT-BR ≠ PT-PT; DE ≠ DE-CH)
- [ ] Moneda y precio local (ej. liras turcas, no dólares → [[proyecto-panes-turcos]])
- [ ] Medidas (convenciones de cocina de EE. UU. → [[proyecto-salad-dressing-bible]])
- [ ] Vocabulario y expresiones
- [ ] Ejemplos, comidas y platos regionales ([[proyecto-come-y-baja]])
- [ ] Fotografías y elementos culturales
- [ ] Texto dentro de imágenes traducido ([[proyecto-babys-first-bites]])
- [ ] Testimonios
- [ ] Voz nativa adecuada ([[videos-y-voces]])
- [ ] Argumentos comerciales, cuando corresponda

Método del mentor para replicar ofertas por mercado: [[internacionalizacion]].
